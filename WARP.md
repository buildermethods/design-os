# Cadence Project Rules

## Directory Structure
This repo has TWO separate apps. NEVER confuse them:
- **Root `./`** — "Design OS" (the planning/design tool by Brian Casel). Package name: `design-os`. Do NOT modify unless explicitly asked.
- **`./cadence-app/`** — The actual Cadence SaaS application. ALL development work happens here.

When editing files, running builds, or installing packages, always target `cadence-app/` unless told otherwise.
